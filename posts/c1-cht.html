1. CLI de Playwright

Comandos fundamentales para instalar, comprobar y administrar Playwright y sus navegadores.

pip install playwright Instalación

Instala la biblioteca de Playwright para Python dentro del entorno virtual activo.

Ejemplo: pip install playwright
playwright --version Diagnóstico

Muestra la versión de Playwright instalada y permite comprobar que el ejecutable está disponible.

Ejemplo: playwright --version
playwright install chromium Browser

Descarga la versión de Chromium compatible con la versión de Playwright instalada.

Ejemplo: playwright install chromium
playwright install --list Browser

Lista los navegadores administrados actualmente por Playwright.

Ejemplo: playwright install --list
playwright install --dry-run Diagnóstico

Muestra qué componentes instalaría Playwright sin ejecutar la instalación.

Ejemplo: playwright install --dry-run
playwright install-deps chromium Linux

Instala las dependencias nativas del sistema necesarias para ejecutar Chromium.

Ejemplo: sudo playwright install-deps chromium

2. Estructura básica de Playwright

La cadena fundamental de ejecución: Playwright → Browser → Page → Locator.

sync_playwright API

Importa la API síncrona de Playwright para Python.

Ejemplo: from playwright.sync_api import sync_playwright
sync_playwright() Runtime

Crea el objeto que permite acceder a los navegadores controlados por Playwright.

Ejemplo: with sync_playwright() as p:
p.chromium Browser

Selecciona el motor Chromium administrado por Playwright.

Ejemplo: browser = p.chromium.launch()
browser.new_page() Page

Crea una nueva página o pestaña dentro del navegador.

Ejemplo: page = browser.new_page()
browser.close() Browser

Cierra el navegador y libera sus recursos.

Ejemplo: browser.close()

3. Lanzamiento del navegador

Configuración básica del proceso Chromium.

launch() Browser

Inicia una instancia del navegador.

Ejemplo: browser = p.chromium.launch()
headless=True Modo

Ejecuta el navegador sin mostrar una ventana gráfica. Es el modo habitual para servidores.

Ejemplo: browser = p.chromium.launch(headless=True)
headless=False Modo

Ejecuta Chromium con interfaz gráfica visible cuando existe una sesión gráfica disponible.

Ejemplo: browser = p.chromium.launch(headless=False)
args=[] Configuración

Permite pasar argumentos directamente al proceso Chromium.

Ejemplo: p.chromium.launch(args=["--disable-gpu"])

4. Navegación

Operaciones fundamentales para desplazarse por una aplicación web.

page.goto() Navegación

Navega la página actual hacia una URL.

Ejemplo: page.goto("https://google.com")
page.reload() Navegación

Recarga la página actual.

Ejemplo: page.reload()
page.go_back() Historial

Retrocede una posición en el historial del navegador.

Ejemplo: page.go_back()
page.go_forward() Historial

Avanza una posición en el historial del navegador.

Ejemplo: page.go_forward()

5. Información de la página

Métodos para inspeccionar el estado básico de la página.

page.title() Lectura

Obtiene el contenido del elemento HTML title de la página.

Ejemplo: titulo = page.title()
page.url Lectura

Devuelve la URL actual de la página.

Ejemplo: print(page.url)
locator() DOM

Crea un Locator para localizar uno o varios elementos del DOM.

Ejemplo: login = page.locator("text=Log in")

6. Selectores y Locator

Los locators son la base para encontrar elementos de forma fiable.

locator("css") CSS

Localiza elementos utilizando selectores CSS.

Ejemplo: page.locator("textarea[name='q']")
get_by_role() ARIA

Localiza elementos utilizando su rol accesible. Es uno de los métodos preferidos para tests robustos.

Ejemplo: page.get_by_role("button", name="Log in")
get_by_text() Texto

Localiza elementos utilizando el texto visible que contienen.

Ejemplo: page.get_by_text("Log in")
get_by_label() Formulario

Localiza un control de formulario asociado a una etiqueta accesible.

Ejemplo: page.get_by_label("Email")
get_by_placeholder() Formulario

Localiza un campo mediante su atributo placeholder.

Ejemplo: page.get_by_placeholder("Buscar")

7. Interacción con elementos

Operaciones esenciales para interactuar con la interfaz web.

click() Interacción

Hace clic sobre el elemento localizado.

Ejemplo: page.get_by_role("button", name="Enviar").click()
fill() Input

Rellena un campo de entrada reemplazando su contenido existente.

Ejemplo: buscador.fill("Playwright Python")
press() Teclado

Envía una pulsación de teclado al elemento.

Ejemplo: buscador.press("Enter")
hover() Interacción

Mueve el puntero sobre el elemento.

Ejemplo: page.locator(".menu").hover()
check() Formulario

Marca un checkbox o radio button cuando corresponde.

Ejemplo: page.get_by_role("checkbox").check()
uncheck() Formulario

Desmarca un checkbox.

Ejemplo: page.get_by_role("checkbox").uncheck()

8. Lectura de elementos

Métodos para obtener información desde el DOM y los controles de formulario.

inner_text() Texto

Obtiene el texto visible de un elemento.

Ejemplo: texto = page.locator("h1").inner_text()
input_value() Input

Obtiene el valor actual de un campo de formulario.

Ejemplo: valor = buscador.input_value()
get_attribute() DOM

Obtiene el valor de un atributo HTML del elemento.

Ejemplo: href = link.get_attribute("href")
count() Locator

Cuenta cuántos elementos coinciden con el locator.

Ejemplo: cantidad = login.count()

9. Aserciones y validación

Las aserciones convierten una automatización en una prueba verificable.

assert Python

Comprueba que una condición sea verdadera. Si falla, Python genera AssertionError.

Ejemplo: assert page.title() == "Google"
expect() Playwright

API de aserciones de Playwright con espera automática para condiciones sobre elementos.

Ejemplo: expect(page).to_have_title("Google")
to_have_text() Expect

Comprueba que un locator contiene el texto esperado.

Ejemplo: expect(page.locator("h1")).to_have_text("Google")
to_be_visible() Expect

Comprueba que el elemento es visible para el usuario.

Ejemplo: expect(login).to_be_visible()

10. Formularios

Operaciones fundamentales para automatizar formularios web.

fill() Input

Introduce texto en un input, textarea u otro control compatible.

Ejemplo: page.locator("input[name='email']").fill("user@example.com")
select_option() Select

Selecciona una opción de un elemento HTML select.

Ejemplo: page.locator("select").select_option("es")
input_value() Validación

Permite verificar posteriormente qué valor quedó introducido en el campo.

Ejemplo: assert campo.input_value() == "texto"

11. Esperas

Playwright utiliza auto-waiting. Las esperas explícitas deben reservarse para casos concretos.

wait_for() Locator

Espera hasta que el locator alcanza el estado solicitado.

Ejemplo: page.locator("#resultado").wait_for()
wait_for_timeout() Tiempo

Espera una cantidad fija de milisegundos. Útil para demostraciones o depuración, no como estrategia normal de sincronización.

Ejemplo: page.wait_for_timeout(3000)
wait_for_url() Navegación

Espera hasta que la URL de la página coincida con el patrón especificado.

Ejemplo: page.wait_for_url("**/dashboard")

12. Contextos y páginas

El contexto permite aislar sesiones, cookies, almacenamiento y configuración del navegador.

browser.new_context() Context

Crea un contexto de navegador aislado del resto de sesiones.

Ejemplo: context = browser.new_context()
context.new_page() Page

Crea una página dentro de un contexto determinado.

Ejemplo: page = context.new_page()
context.close() Context

Cierra el contexto y libera sus recursos asociados.

Ejemplo: context.close()

14. Plantilla de automatización

Estructura mínima reutilizable para comenzar una prueba.

plantilla Python

Esqueleto completo de una automatización síncrona básica.

Ejemplo: from playwright.sync_api import sync_playwright

with sync_playwright() as p:
browser = p.chromium.launch(headless=True)
page = browser.new_page()
page.goto("https://example.com")
print(page.title())
browser.close()

16. Reglas mentales fundamentales

La secuencia que conviene interiorizar para razonar cualquier automatización.

1. goto Flujo

Primero lleva el navegador al recurso que quieres automatizar.

Ejemplo: page.goto("https://example.com")
2. locate Flujo

Después identifica exactamente qué elemento del DOM necesitas controlar.

Ejemplo: campo = page.locator("input[name='q']")
3. interact Flujo

Realiza la acción necesaria sobre el elemento localizado.

Ejemplo: campo.fill("Playwright")
4. verify Flujo

Comprueba que la aplicación produjo el resultado esperado.

Ejemplo: assert campo.input_value() == "Playwright"
