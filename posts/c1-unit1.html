Instalación de Playwright en Debian Linux

24/08/2026 Tutorial Nivel: Intermedio

Instalación y configuración manual de Playwright con Python y Chromium en Debian Linux. El objetivo es comprender cada componente del entorno y aprender a verificarlo de forma independiente.

1. Preparar Debian

Antes de instalar cualquier componente debemos identificar exactamente qué sistema operativo estamos utilizando. Esto permite comprobar que las instrucciones corresponden al entorno real.

bash
# Mostrar información del sistema
cat /etc/os-release

En Debian 13 deberíamos encontrar información similar a:

text
PRETTY_NAME="Debian GNU/Linux 13 (trixie)"
ID=debian
VERSION_ID="13"

También verificamos el usuario actual:

bash
whoami

Este punto es importante porque Playwright y Python se instalarán dentro del usuario que ejecutará posteriormente las automatizaciones.

2. Verificar privilegios administrativos

Algunas operaciones requieren modificar el sistema operativo. Sin embargo, Playwright no debe instalarse como root.

Comprobamos que nuestro usuario dispone de privilegios mediante sudo:

bash
sudo -v

La instalación quedará separada en dos niveles:

  • Python, virtualenv, Playwright y Chromium pertenecen al usuario.
  • Las dependencias del sistema se instalan mediante sudo.
  • No ejecutaremos pip como root.

3. Instalar Python y herramientas necesarias

Playwright para Python necesita un intérprete Python y un entorno virtual. Debian proporciona estos componentes mediante sus paquetes oficiales.

Primero actualizamos la información de los repositorios:

bash
sudo apt update

Después instalamos Python, pip y el módulo necesario para crear entornos virtuales:

bash
sudo apt install python3 python3-venv python3-pip

Verificamos la instalación:

bash
python3 --version
pip3 --version

4. Crear el entorno virtual

No instalaremos Playwright directamente en el Python global del sistema. Crearemos un entorno virtual independiente para mantener aisladas sus dependencias.

bash
python3 -m venv ~/playwright-env

El entorno se crea en:

text
/home/administrator/playwright-env

Ahora lo activamos:

bash
source ~/playwright-env/bin/activate

El prompt debe mostrar el nombre del entorno:

text
(playwright-env) administrator@CLI01-DBNLNX:~$

Finalmente comprobamos qué Python estamos utilizando:

bash
which python

5. Instalar Playwright para Python

Con el entorno virtual activo instalamos Playwright mediante pip. La instalación queda contenida dentro de nuestro entorno virtual.

bash
pip install playwright

Comprobamos la versión instalada:

bash
playwright --version

6. Instalar Chromium

Playwright no depende necesariamente del navegador instalado por el sistema. Descarga y administra las versiones de navegador que corresponden a su propia versión.

Instalamos Chromium:

bash
playwright install chromium

Podemos consultar qué instalaría Playwright sin realizar ninguna modificación:

bash
playwright install --dry-run

Los navegadores administrados por Playwright se almacenan normalmente dentro de:

text
~/.cache/ms-playwright/

7. Instalar dependencias de Chromium

Descargar Chromium no garantiza que pueda ejecutarse. El navegador necesita determinadas bibliotecas y componentes del sistema Linux.

Playwright proporciona un mecanismo para instalar las dependencias necesarias:

bash
sudo playwright install-deps chromium

Aquí sí utilizamos sudo, porque estamos instalando paquetes pertenecientes al sistema Debian.

Playwright se instala en el entorno virtual del usuario; las dependencias nativas necesarias para ejecutar Chromium pertenecen al sistema operativo.

8. Verificar permisos

Los archivos creados dentro del HOME deben pertenecer al usuario que ejecutará Playwright.

Buscamos elementos que tengan otro propietario:

bash
find "$HOME" -maxdepth 2 \( ! -user "$USER" -o ! -group "$USER" \) -ls

Esta comprobación es especialmente importante cuando anteriormente se han ejecutado comandos de Chromium o Playwright como root.

9. Verificar Chromium directamente

Antes de involucrar a Playwright comprobamos que el navegador descargado puede ejecutarse por sí mismo.

Localizamos el binario:

bash
find ~/.cache/ms-playwright -type f -path '*/chrome-linux64/chrome'

Comprobamos la versión:

bash
~/.cache/ms-playwright/chromium-*/chrome-linux64/chrome --version

10. Comprobar el entorno gráfico

Una ejecución con headless=False necesita acceso a una sesión gráfica. Por eso comprobamos las variables y servicios relacionados con la sesión del usuario.

bash
echo "$DISPLAY"
echo "$XDG_SESSION_TYPE"

También comprobamos el bus D-Bus del usuario:

bash
systemctl --user status dbus --no-pager

El objetivo es confirmar que existe una sesión gráfica funcional antes de intentar ejecutar el navegador en modo visible.

11. Primera prueba de Chromium

Ejecutamos directamente el navegador descargado por Playwright. Esta prueba permite aislar Chromium de Playwright.

bash
~/.cache/ms-playwright/chromium-*/chrome-linux64/chrome --no-sandbox --disable-gpu --user-data-dir=/tmp/chrome-test

Si Chromium permanece ejecutándose, podemos continuar con la prueba de Playwright.

En esta fase no estamos probando automatización. Estamos comprobando únicamente que el navegador puede arrancar correctamente en Debian.

12. Primera prueba con Playwright

Con Chromium funcionando pasamos finalmente a la API de Playwright.

Ejecutamos una prueba mínima que abre Chromium, crea una página y navega hasta Google.

bash
python -c "from playwright.sync_api import sync_playwright; p=sync_playwright().start(); b=p.chromium.launch(headless=False,args=['--disable-gpu']); page=b.new_page(); page.goto('https://google.com'); page.wait_for_timeout(15000)"

La cadena de ejecución es:

  • Python inicia Playwright.
  • Playwright inicia Chromium.
  • Se crea un contexto de navegador.
  • Se crea una página.
  • La página navega hacia Google.
  • El navegador permanece abierto durante 15 segundos.

Si Chromium se abre y Google carga correctamente, el entorno básico de automatización gráfica está operativo.

13. Generar información de diagnóstico

Un entorno de automatización debe poder describirse técnicamente. Esto permite diagnosticar problemas sin reconstruir manualmente toda la instalación.

Generamos un pequeño informe con la información fundamental:

bash
echo "===== SYSTEM =====" > ~/playwright-environment.txt
cat /etc/os-release >> ~/playwright-environment.txt
uname -a >> ~/playwright-environment.txt
echo "===== USER =====" >> ~/playwright-environment.txt
whoami >> ~/playwright-environment.txt
id >> ~/playwright-environment.txt
echo "===== PYTHON =====" >> ~/playwright-environment.txt
python3 --version >> ~/playwright-environment.txt
python --version >> ~/playwright-environment.txt
echo "===== PLAYWRIGHT =====" >> ~/playwright-environment.txt
playwright --version >> ~/playwright-environment.txt
playwright install --list >> ~/playwright-environment.txt
echo "===== DISPLAY =====" >> ~/playwright-environment.txt
echo "DISPLAY=$DISPLAY" >> ~/playwright-environment.txt
echo "XDG_SESSION_TYPE=$XDG_SESSION_TYPE" >> ~/playwright-environment.txt

El resultado queda almacenado en:

text
~/playwright-environment.txt

Este archivo permite proporcionar a otra persona o a una IA una descripción técnica reproducible del entorno: sistema operativo, usuario, Python, Playwright, navegadores y sesión gráfica.

Resultado final

Al completar el módulo no solamente tendremos Playwright instalado. Habremos construido y comprobado cada componente de la cadena de ejecución.

text
Debian
└── Python
└── venv
└── Playwright
└── Chromium
└── Entorno gráfico
└── Automatización

La instalación termina cuando podemos demostrar que cada capa funciona, no simplemente cuando el paquete aparece instalado.
